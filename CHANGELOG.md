# Changelog

## 0.0.2 (06/28/2026)
* Adds React Native Cohort Replay support (Beta), including manual element masking via nativeID="cr-no-capture".
* maskAllTextInputs — New option to mask only editable text fields (UITextField, UITextView, SwiftUI text inputs, React Native ) while leaving static labels and read-only text visible. Narrower than maskAllInputs; enabled by default.
* Expanded maskInputOptions — Added support for datetime, grouped keys personName and postalAddress, and iOS 17+ types including creditCardExpiration, creditCardSecurityCode, and birthdate variants.

## 0.0.1 (03/18/2026)
* Introduces Cohort Replay (Beta)
    * Cohort Replay enables the visual reconstruction and review of user navigations and actions within a customer's app. This feature captures how users interact with the app, including clicks, navigation, scrolling, media engagement, and text input, and then replays these interactions in a video-like experience.
NOTE: By default, Cohort Replay is disabled. To enable it, please contact the Conviva Support team.
